# 機能一覧

CSV nyaan Viewerの実装機能と検証状況をまとめています。

| 分類 | 実装内容 | 検証 |
| --- | --- | --- |
| 非破壊閲覧 | 元CSVはread-onlyのファイル記述子で開く。SHA-256・更新日時保持 | 自動テスト |
| データ保持 | 先頭ゼロ・長い整数・日付・数式文字列は文字列のまま | 自動テスト |
| CSV構文 | 引用符、二重引用符、セル内改行、CRLF/LF/CR、空セル、末尾空セル | 自動テスト |
| 区切り文字 | カンマ・タブ・セミコロン・パイプ・任意ASCII1文字 | 自動テスト |
| 文字コード | UTF-8、CP932、EUC-JP、UTF-16/32 LE/BE、1252、Latin-1 | 自動テスト／一部手動指定 |
| 表示 | タブ、見出し固定、列固定・非表示、リサイズ、フォント・サイズ | UI検証 |
| 選択 | 単一／複数範囲、Ctrl追加、Shift拡張、行選択、全選択 | 自動テスト |
| 検索 | 部分・セル全体・大小文字・正規表現・前後循環 | 自動テスト |
| 絞り込み | 複数条件AND、列／全列、文字列・空欄・数値比較 | 自動テスト |
| 並べ替え | 複数列、自然順、精度を保持した10進数比較、安定順 | 自動テスト |
| コピー・移動 | TSVコピー、全文セルコピー、行列移動、キーボード操作 | 自動／UIテスト |
| 大容量 | Worker索引・遅延読み込み、表示仮想化、巨大スクロールの縮尺 | 100万レコード検証 |
| ファイル管理 | 複数ファイル、履歴、再読込、外部更新検知、フォルダー表示 | 自動／UIテスト |
| Excel | XLSX/XLS/XLSB等、テンプレート、複数シート、保存済み表示値、元ファイル不変 | 自動／UIテスト |
| オンライン | URL入力・ドロップ、公開Excel、Google/Microsoft認証付き読み取り | API契約／UIテスト。実アカウント未検証 |
| 分析 | 分布・法則・相関・回帰、全域標本、全シート、PCA 2D/3D・k-means | 既知値テスト／UIテスト |
| Markdown / TXT | ネイティブソース、Markdownプレビュー・表セル選択 | UIテスト |
| エクスポート | CSV / TSV / MD / TXT、全体・表示・選択、元ファイル上書き拒否 | 自動／UIテスト |
| ダッシュボード | Excel系の各グラフ分類とバリエーション、実X/Y散布図、7種類の配色、自動推薦、推定見出し・ラベル、X/Y軸のホバー選択・クリック編集 | 自動／UIテスト |
| 画像出力 | PNG、上部ネイティブメニュー／プレビュー／右クリック。PNG・GIF・MD/XLSX埋め込み画像は白基調が既定、ダーク／画面追従も選択可能。分析画像は文字の折り返しと縦横比保持、XLSXは画像寸法に応じた配置 | 自動／UIテスト |
| 結合 | Markdownのテキスト・表・グラフブロック、原文切り替え、直接クリック編集・削除、独立したグラフ軸編集、画像付き.md保存、表の縦／横結合 | 自動／UIテスト |
| ペイン | 全6ペインを独立タブ化、グラフ／テーブルは別タブ、開閉ボタン・タブのドラッグで上下左右への移動・結合・並べ替え、個別開閉と状態保持、配置・並び順・選択タブの再起動復元、全境界ドラッグ、閉領域の再表示、上下左右・左上右下の6箇所のドット型つまみで幅・高さ／両方を調整、サイズ保存・初期サイズ復元、別ウィンドウ | UIテスト |
| カラー | M365 / Fluent参考のライト・ダーク・青／緑／紫 | UIテスト |
| アイコン | 指定画像をWindows実行ファイル・ウィンドウ・タスクバー・左上に組み込み、設定で変更可能 | 実行ファイルのリソース／同梱PNG検証・UIテスト |
| アプリ情報 | オブザーバーBLINP_B(furoneko+)と関連リンクを表示 | UIテスト |
| 配布署名 | 検証用自己署名、公開証明書同梱、Authenticode検証と結果出力 | 設定テスト／Windows検証。自己署名のため利用環境での信頼登録が必要 |
| アカウント共有 | Google / Microsoft OAuth PKCE、GitHub Device、Bot/Webhook | 契約テスト。実接続は未検証 |

通常の閲覧では元ファイルを書き換えません。

GitHub ActionsのWindows環境でコア・Electron UIテスト、配布ZIPの生成、実行ファイルのアイコンリソースの確認を行います。ローカル作業環境でのElectron UIテストにはLinuxを使用します。

Excelのグラフ分類をプルダウンに実装していますが、Excel固有のオブジェクト・ピボット・地理データ型や完全な書式互換はありません。3DはCPU投影、地図は国単位です。
