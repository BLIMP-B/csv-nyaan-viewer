Windows 10 / 11（x64）向け CSV nyaan Viewer 1.4.0です。

Assetsの `CSV-nyaan-Viewer-1.4.0-Windows-x64.zip` をすべて展開して `CSV nyaan Viewer.exe` を起動してください。Node.jsは不要です。

- ワークスペース・変量分析・多変量分析・グラフプレビュー・テーブルプレビュー・ファイル結合を、それぞれ独立したタブとして扱います。
- タブや境界の開閉ボタンを上下左右へドラッグして、移動・タブ結合・並べ替えできます。閉じたタブのボタンからも移動でき、ドラッグ中は結合先を表示します。Escで取り消せます。
- タブごとに開閉でき、他のタブや分析設定・表の名前・編集中の結合文書を保持します。配置・並び順・開閉状態・選択中のタブは再起動後も復元します。一時テーブルと結合文書はアプリ終了時に消えます。
- 同じ位置のタブグループを別ウィンドウにでき、別ウィンドウ内でもタブを切り替えられます。従来の位置プルダウン、境界ドラッグ、6箇所のドット型つまみも利用できます。

コア100件・Electron UI31件の全131件をWindowsで実行し、アイコンとAuthenticode署名を検証して配布します。検証には架空のデータを使用します。提出資料とその内容はリポジトリ・配布物に含めません。

表・役割・照合キーは推定です。「対象・除外・合流の判断結果」を確認し、必要に応じて列のチェックボックス、指定範囲、一時テーブルで調整してください。操作と上限はREADMEを参照してください。

検証用の自己署名版です。公開証明書 `test-signing.cer` と検証結果 `SIGNATURE.json` を配布します。以前の証明書を登録している場合は新しい拇印を確認して更新してください。手順は [Windowsコード署名](https://github.com/BLIMP-B/csv-nyaan-viewer/blob/main/docs/code-signing.md) を参照してください。

既存のペイン開閉・シート表示条件の保持・グラフ・テーブル管理・出力・共有・接続機能を含みます。外部アカウントの実接続にはOAuth登録が必要で、実接続は未検証です。Excel固有のチャート・ピボットの完全互換は未対応です。
