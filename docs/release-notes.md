Windows 10 / 11（x64）向けのCSV・Markdown・TXTビューワーです。

「Assets」から `CSV-nyaan-Viewer-1.0.2-Windows-x64.zip` をダウンロードし、すべて展開して `CSV nyaan Viewer.exe` を起動してください。Node.jsのインストールは不要です。

- 元ファイルを書き換えず、先頭ゼロ・長い整数・文字コードを保持して閲覧。
- Ctrlによる複数範囲選択からグラフを表示。下段・右側のX/Y軸を直接クリックして編集。
- ドット型つまみでペインの幅・高さを調整し、設定を保存。
- テキスト・表・グラフをMarkdownブロックとして結合し、画像付き.mdを出力。
- CSV / TSV / MD / TXTのエクスポート、接続設定と共有機能。

ソースZIPとSHA-256チェックサムも添付しています。OAuth等の接続情報は含みません。サービス連携には利用者自身のアプリ登録が必要です。

Modern CSV無料版との完全な機能照合、外部アカウントへの実接続、Windows実機での手動操作は未検証です。自動ビルド・テストの結果はリポジトリの「Actions」で確認できます。
