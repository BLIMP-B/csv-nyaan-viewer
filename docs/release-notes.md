Windows 10 / 11（x64）向け CSV nyaan Viewer 1.5.1です。

Assetsの `CSV-nyaan-Viewer-1.5.1-Windows-x64.zip` をすべて展開して `CSV nyaan Viewer.exe` を起動してください。Node.jsは不要です。

- OBJの点を大きな球体メッシュに変更しました。元の座標を中心に置き、3Dソフトで読み込んでも大きさを保持します。
- OBJに矢印付きのX・Y・Z軸と、選択中のPC／元データの列名を示す立体文字を追加しました。日本語名も同じファイルの形状として含み、追加のフォントや画像ファイルは不要です。
- 点の半径は最大絶対座標の2.5%（基準値の下限は1）です。長い軸名は折り返して表示し、12行を超えた部分は省略します。完全な軸名はOBJ内のコメントに保持します。表示で系列線を有効にした場合は線も出力します。

コア109件・Electron UI34件の全143件をWindowsで実行し、アイコンとAuthenticode署名を検証して配布します。球体の中心・半径・面の向き・閉じた形状、頂点の参照、軸と日本語の軸名メッシュを確認します。

検証用の自己署名版です。公開証明書 `test-signing.cer` と検証結果 `SIGNATURE.json` を配布します。以前の証明書を登録している場合は新しい拇印を確認して更新してください。手順は [Windowsコード署名](https://github.com/BLIMP-B/csv-nyaan-viewer/blob/main/docs/code-signing.md) を参照してください。

既存の閲覧・分析・グラフ・出力・ペイン移動・共有・接続・S共有・Sアカウント接続機能を含みます。カメラの向きはOBJへ焼き込まず、読み込み先で視点を変更します。S接続の実サービスでのログイン・送信は未検証です。
