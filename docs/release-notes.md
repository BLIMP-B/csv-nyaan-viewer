Windows 10 / 11（x64）向け CSV nyaan Viewer 1.5.8です。

Assetsの `CSV-nyaan-Viewer-1.5.8-Windows-x64.zip` をすべて展開して `CSV nyaan Viewer.exe` を起動してください。Node.jsは不要です。

- S共有・Sアカウント接続で読み込みが失敗すると空白ページが残る問題を修正しました。読み込み中の表示と、通信・プロキシ・証明書・描画のエラー表示を追加しました。
- 初回読み込み失敗後も接続先URLを保持し、元のURLへの「再試行」、「サービスのトップを開く」、「外部ブラウザで開く」に対応します。再読み込みで空のページを開き直す経路を修正しました。
- URL移動が読み込み完了まで操作を待たせる問題を修正しました。読み込み中のURL変更を受け付け、正常な移動による中断はエラーにしません。
- 接続入口はサービスのトップを開きます。共有データがある場合はメール作成画面などを使用し、添付準備・本文コピー・アカウントの保存を保持します。
- ライト・ダーク両配色の失敗画面と入力欄に対応し、11サービスの表示領域・描画、再試行、about:blankからの認証ポップアップ、描画停止からの復帰を検証しました。

コア131件・Electron UI46件の全177件をWindowsで実行し、アイコンとAuthenticode署名を検証して配布します。実サービスの公開ページの表示は空のプロファイルで別途確認し、ActionsのS-browser-public-page-checkへ結果を保存します。ログイン・添付・送信の成功を保証する検証ではありません。サービスの認証制限や通信設定は、表示された内容を確認してください。

検証用の自己署名版です。公開証明書 `test-signing.cer` と検証結果 `SIGNATURE.json` を配布します。以前の証明書を登録している場合は新しい拇印を確認して更新してください。手順は [Windowsコード署名](https://github.com/BLIMP-B/csv-nyaan-viewer/blob/main/docs/code-signing.md) を参照してください。
