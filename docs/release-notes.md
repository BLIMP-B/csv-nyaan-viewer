Windows 10 / 11（x64）向け CSV nyaan Viewer 1.5.3です。

Assetsの `CSV-nyaan-Viewer-1.5.3-Windows-x64.zip` をすべて展開して `CSV nyaan Viewer.exe` を起動してください。Node.jsは不要です。

- ペイン内部のタブ列を廃止し、上下左右それぞれの境界へタブ名のボタンを統合しました。グラフプレビュー・テーブルプレビューも境界のボタンで切り替えます。
- 領域ごとに共通の開閉アイコン1個を置き、その隣に文字のタブボタンを分けて並べます。閉じている場合はどちらからでも領域全体を展開します。開いている場合は文字で内容を切り替え、共通アイコンで領域全体を最小化します。見出しの×も一括最小化に利用できます。
- 同じ側の一部だけ閉じたボタンがデータ領域へ浮く状態を解消しました。旧版の部分開閉設定を領域単位へ移行し、位置・順序・選択タブ・サイズを保持します。
- タブ名をドラッグして上下左右への移動・結合・並べ替えができます。切り替え・開閉・移動・別ウィンドウ化でも分析設定、表の名前、編集中の文書を保持します。境界とドット型つまみでサイズを変更できます。

コア119件・Electron UI36件の全155件をWindowsで実行し、アイコンとAuthenticode署名を検証して配布します。全方向で6タブの結合、一括展開・最小化、文字による切り替え、境界位置、サイズ・内容保持、ドラッグ・並べ替え、別ウィンドウと再起動復元を確認します。既存のプロフィール画像取得には模擬サービスを使用し、実アカウントのログイン・画像取得・送信は未検証です。

検証用の自己署名版です。公開証明書 `test-signing.cer` と検証結果 `SIGNATURE.json` を配布します。以前の証明書を登録している場合は新しい拇印を確認して更新してください。手順は [Windowsコード署名](https://github.com/BLIMP-B/csv-nyaan-viewer/blob/main/docs/code-signing.md) を参照してください。

既存の閲覧・分析・グラフ・出力・共有・接続・S共有・Sアカウント接続機能を含みます。
