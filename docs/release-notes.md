Windows 10 / 11（x64）向け CSV nyaan Viewer 1.1.0です。

「Assets」の `CSV-nyaan-Viewer-1.1.0-Windows-x64.zip` をすべて展開して `CSV nyaan Viewer.exe` を起動してください。Node.jsは不要です。

- ドット型つまみを上下左右・左上・右下に配置。境界全体のドラッグでリサイズ、閉じた領域の再表示に対応。
- Ctrl／Shift／矢印の範囲操作、行・列中央の選択とドラッグ、表示・ソート・フィルター・表示削除のメニューを追加。
- Excel系のグラフ分類とバリエーション、7種類の配色、データによる初期グラフの推定。
- 左サイドに変量分析・多変量分析。相関・回帰・主成分分析の2D／3D・群候補を表示。
- Excel各形式をCSVに変換せず閲覧。複数シート、URL入力・URLドロップによるオンラインExcel／Google Sheets読み取り。
- PNG／ICOを設定から選び、アプリのウィンドウ・タスクバーアイコンを変更可能。

コア／API契約／Excel／分析／描画テスト57件とElectron UIテスト16件を実行するWindows自動ビルドです。ソースZIP・SHA-256チェックサムを添付しています。

外部アカウントの実接続にはOAuthアプリ登録が必要で、実アカウントでの接続は未検証です。3Dは投影表示、地図は国単位です。Excel固有のグラフオブジェクト・ピボット等の完全互換はありません。指定アイコン画像は作業環境の403制限で未取得のため、実行ファイルへの埋め込みは未完了です。Modern CSV無料版との完全な機能照合も未完了です。
