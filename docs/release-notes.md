Windows 10 / 11（x64）向け CSV nyaan Viewer 1.1.7です。

「Assets」の `CSV-nyaan-Viewer-1.1.7-Windows-x64.zip` をすべて展開して `CSV nyaan Viewer.exe` を起動してください。Node.jsは不要です。

- 複数シートのExcel・オンラインブックでは、データ領域の下端にExcel風のシートタブを表示します。上部のシート選択プルダウンをタブへ移しました。
- 全シート名を並べ、選択中のシートを強調表示します。多数のタブは横スクロールと左右ボタンで閲覧できます。
- タブにフォーカスした状態で左右矢印・Home・Endによる切り替えが可能です。選択したタブを自動で表示範囲へ移動します。
- シート切り替え時に、前のシートのフィルター・ソート・非表示・固定列などの表示条件を初期化します。空のシートでも一覧を表示し、ほかのシートへ移動できます。
- 空・短いシートを経由しても、指定した見出し行数を保持するように修正しました。
- ファイルごとに正しい一覧を表示し、単一シートやCSVにはシートタブの行を追加しません。全3アクセント・ライト／ダークで文字の読みやすさを確認します。
- 検証用の自己署名コード署名を継続。公開証明書 `test-signing.cer` と署名検証結果 `SIGNATURE.json` を配布します。

前版のグレー表示・テーマ配色、URL欄配置・オブザーバー表示・指定アイコン、Excel・オンライン読み取り、グラフ・分析、範囲選択、ペイン調整機能を含みます。コア／API契約／Excel／分析／描画／署名設定テスト65件とElectron UIテスト21件を実行するWindows自動ビルドです。ソースZIP・SHA-256チェックサム・署名検証結果を添付しています。[テーマ配色の確認](https://github.com/BLIMP-B/csv-nyaan-viewer/blob/main/docs/theme-audit.md) に確認対象と検証方法を記載しています。

自己署名は認証局による本人・組織確認を受けた証明書ではありません。他のWindows環境で署名を信頼する場合は、公開証明書の拇印を確認して検証用アカウントへ手動登録してください。手順は [Windowsコード署名](https://github.com/BLIMP-B/csv-nyaan-viewer/blob/main/docs/code-signing.md) を参照してください。

外部アカウントの実接続にはOAuthアプリ登録が必要で、実アカウントでの接続は未検証です。3Dは投影表示、地図は国単位です。Excel固有のグラフオブジェクト・ピボット等の完全互換はありません。Modern CSV無料版との完全な機能照合も未完了です。
