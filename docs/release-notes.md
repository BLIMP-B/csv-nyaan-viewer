Windows 10 / 11（x64）向け CSV nyaan Viewer 1.5.4です。

Assetsの `CSV-nyaan-Viewer-1.5.4-Windows-x64.zip` をすべて展開して `CSV nyaan Viewer.exe` を起動してください。Node.jsは不要です。

- 多変量分析のグラフ内に「PCと色の見方」を追加しました。PC1・PC2・PC3の意味、1点が表す観測、現在のプロット色の凡例を確認できます。
- 「PC1・PC2・PC3とファイル処理・算出方法」を開くと、読み取り・対応付け・自動除外・合流設定、欠損行の除外、標準化、共分散行列とJacobi法、PC座標・係数・寄与率、k-means群分けと描画上限を確認できます。寄与率、対象行数・変量数、群数と設定は実際の分析結果を反映し、2変量の場合はPC3が未算出であることを表示します。
- 通常の色は推定した群、2系列比較時の色は系列を表すと説明し、凡例を切り替えます。群の件数は間引き前の完全な数値行の件数です。回転・軸変更と群分けの関係、寄与率と予測精度の違いも説明します。
- 解説と凡例は、折りたたみ状態に関係なく多変量分析の.md・.xlsx出力にも含めます。ライト・ダーク両方の表示に対応します。
- 前版の境界タブ、領域単位の展開・最小化、ペイン移動・別ウィンドウ化、アカウントのプロフィール画像表示を保持します。

コア120件・Electron UI36件の全156件をWindowsで実行し、アイコンとAuthenticode署名を検証して配布します。凡例と実際のプロット色の一致、群と2系列の切り替え、少数行の群分けなし、未算出PC、描画を間引いた際の件数、折りたたんだ解説のMD・XLSX出力、ライト・ダークの文字コントラストを検証します。既存のプロフィール画像取得には模擬サービスを使用し、実アカウントのログイン・画像取得・送信は未検証です。

検証用の自己署名版です。公開証明書 `test-signing.cer` と検証結果 `SIGNATURE.json` を配布します。以前の証明書を登録している場合は新しい拇印を確認して更新してください。手順は [Windowsコード署名](https://github.com/BLIMP-B/csv-nyaan-viewer/blob/main/docs/code-signing.md) を参照してください。
