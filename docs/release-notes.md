Windows 10 / 11（x64）向け CSV nyaan Viewer 1.3.0です。

Assetsの `CSV-nyaan-Viewer-1.3.0-Windows-x64.zip` をすべて展開して `CSV nyaan Viewer.exe` を起動してください。Node.jsは不要です。

- 多変量分析の自動判断を改善しました。ID・コード・期間・分類を測定変量から除外し、数値と文章が混在する列も判定します。連番の測定値は保持します。
- 自動判断を基本に、除外・使用・同名列の合流を全体または列別のチェックボックスで変更できます。判断理由と設定を画面・MD・XLSX出力に含めます。
- 値のない書式範囲を除き、複数段の見出しと主表の区切りを推定します。横持ちの数値表を観測別に整理し、異なる測定項目は分けて比較します。ファイル名・シート名による専用処理はありません。
- 店舗などの識別子と期間を複合照合します。観測単位が異なる表は別グループに分け、キーが欠けた行を無理に合流しません。大きな表も可能な範囲で照合を先に行ってから標本を抽出します。
- 相関の上限を64変量に増やしました。既定の相関表示は3組以上を対象とし、8組未満は参考値であることを表示します。値の不一致や標本だけで一致を確認できない同名列は別系列に保持します。

コア93件・Electron UI26件の全119件をWindowsで実行し、アイコンとAuthenticode署名を検証して配布します。検証には架空のデータを使用します。提出資料とその内容はリポジトリ・配布物に含めません。

表・役割・照合キーは推定です。「対象・除外・合流の判断結果」を確認し、必要に応じて列のチェックボックス、指定範囲、一時テーブルで調整してください。操作と上限はREADMEを参照してください。

検証用の自己署名版です。公開証明書 `test-signing.cer` と検証結果 `SIGNATURE.json` を配布します。以前の証明書を登録している場合は新しい拇印を確認して更新してください。手順は [Windowsコード署名](https://github.com/BLIMP-B/csv-nyaan-viewer/blob/main/docs/code-signing.md) を参照してください。

既存のペイン開閉・シート表示条件の保持・グラフ・テーブル管理・出力・共有・接続機能を含みます。外部アカウントの実接続にはOAuth登録が必要で、実接続は未検証です。Excel固有のチャート・ピボットの完全互換、およびModern CSV無料版の完全な機能照合は未完了です。
