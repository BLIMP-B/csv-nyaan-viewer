Windows 10 / 11（x64）向け CSV nyaan Viewer 1.2.0です。

Assetsの `CSV-nyaan-Viewer-1.2.0-Windows-x64.zip` をすべて展開して `CSV nyaan Viewer.exe` を起動してください。Node.jsは不要です。

- 変量分析は非表示の行・列を除外。法則のある個別項目を展開するとグラフを表示し、個別PNG保存に対応しました。
- 変量・多変量のMD／XLSX出力は、折りたたみ状態にかかわらず全統計・相関・グラフを収録します。XLSXはグラフ画像と描画データも含みます。
- 多変量は分析シート・選択範囲・全域・指定テーブルのラジオボタンで対象を選択。全域集計は▷で明示的に開始します。
- 複数シート・ファイルの範囲選択と表示条件を保持。共通の行名は名前で対応し、同名列は値が一致すれば合流します。不一致は別系列として残し、名前が対応しない場合は行位置を用います。
- Ctrl＋Tの一時テーブル、色付きセル、名称編集、番地追加、プレビュー／右クリックでの削除を追加しました。
- 3D方向ホイール、水平回転バー、自動回転、PCと元列を各軸2項目まで選ぶ2系列の比較、軸名とカテゴリー説明を追加しました。
- 2DはPNG、3Dは現在の向きから2周するGIFと座標・点・接続線のOBJを出力し、軸の項目をファイル名に付けます。

既存の読み取り専用CSV・Excel・Markdown・TXT閲覧、テーマ、シート／モードタブ、共有・接続、結合、ペイン調整機能を含みます。コアテスト77件・Electron UIテスト24件をWindowsでも実行し、アイコンとAuthenticode署名を検証して配布します。

集計・主成分・群は標本に基づく推定です。集計は最大5,000行・250,000セル・256列、相関32変量・主成分16変量・描画500点／系列です。XLSXのグラフは画像で、編集可能なExcelチャートではありません。テーブルは一時保存で、終了時に消えます。詳しい操作・対応方法・上限はREADMEを参照してください。

検証用の自己署名版です。公開証明書 `test-signing.cer` と検証結果 `SIGNATURE.json` を配布します。以前の証明書を登録している場合は新しい拇印を確認して更新してください。手順は [Windowsコード署名](https://github.com/BLIMP-B/csv-nyaan-viewer/blob/main/docs/code-signing.md) を参照してください。

外部アカウントの実接続にはOAuth登録が必要で、実接続は未検証です。Excel固有のチャート・ピボットの完全互換、およびModern CSV無料版の完全な機能照合は未完了です。
