Windows 10 / 11（x64）向け CSV nyaan Viewer 1.3.3です。

Assetsの `CSV-nyaan-Viewer-1.3.3-Windows-x64.zip` をすべて展開して `CSV nyaan Viewer.exe` を起動してください。Node.jsは不要です。

- XLSXの埋め込みグラフが縦横に引き伸ばされないよう、画像本来の縦横比を保持します。画像の高さに応じて行を確保し、次のグラフとの重なりを防ぎます。
- 分析画像のタイトル・軸名・凡例の領域を分け、長い文字を折り返します。3Dの軸名は引き出し線で示し、主成分の縮尺は縦横でそろえます。
- 出力画像はダーク画面でも白基調が初期設定です。「設定 → 出力画像の配色」で白基調・ダーク・画面追従を変更できます。PNG・GIF・MD/XLSXと結合文書のグラフに共通で適用します。

コア96件・Electron UI28件の全124件をWindowsで実行し、アイコンとAuthenticode署名を検証して配布します。検証には架空のデータを使用します。提出資料とその内容はリポジトリ・配布物に含めません。

表・役割・照合キーは推定です。「対象・除外・合流の判断結果」を確認し、必要に応じて列のチェックボックス、指定範囲、一時テーブルで調整してください。操作と上限はREADMEを参照してください。

検証用の自己署名版です。公開証明書 `test-signing.cer` と検証結果 `SIGNATURE.json` を配布します。以前の証明書を登録している場合は新しい拇印を確認して更新してください。手順は [Windowsコード署名](https://github.com/BLIMP-B/csv-nyaan-viewer/blob/main/docs/code-signing.md) を参照してください。

既存のペイン開閉・シート表示条件の保持・グラフ・テーブル管理・出力・共有・接続機能を含みます。外部アカウントの実接続にはOAuth登録が必要で、実接続は未検証です。Excel固有のチャート・ピボットの完全互換は未対応です。
