Windows 10 / 11（x64）向け CSV nyaan Viewer 1.1.6です。

「Assets」の `CSV-nyaan-Viewer-1.1.6-Windows-x64.zip` をすべて展開して `CSV nyaan Viewer.exe` を起動してください。Node.jsは不要です。

- CSV・Excelの最上段を `#` と `A・B・C…・AA…` の列記号だけにしました。ファイルの1行目はその下に行番号 `1` を付けて独立して表示します。
- 複数行の見出しは、元の空欄・改行・先頭ゼロを保持して行ごとに表示します。ダブルクリックで全文確認・コピーができます。
- 見出し行数0では先頭レコードから通常のセルとして表示します。見出し行が多い場合は見出し部分を独立してスクロールでき、データ領域を確保します。
- 列選択、ソート、固定列、縦横スクロール、シート切り替えと両テーマでの表示を確認するテストを追加しました。見出し名はグラフ・フィルター・エクスポートでも引き続き使用します。
- 検証用の自己署名コード署名を継続。公開証明書 `test-signing.cer` と署名検証結果 `SIGNATURE.json` を配布します。

前版のグレー表示・テーマ配色、URL欄配置・オブザーバー表示・指定アイコン、Excel・オンライン読み取り、グラフ・分析、範囲選択、ペイン調整機能を含みます。コア／API契約／Excel／分析／描画／署名設定テスト64件とElectron UIテスト19件を実行するWindows自動ビルドです。ソースZIP・SHA-256チェックサム・署名検証結果を添付しています。[テーマ配色の確認](https://github.com/BLIMP-B/csv-nyaan-viewer/blob/main/docs/theme-audit.md) に確認対象と検証方法を記載しています。

自己署名は認証局による本人・組織確認を受けた証明書ではありません。他のWindows環境で署名を信頼する場合は、公開証明書の拇印を確認して検証用アカウントへ手動登録してください。手順は [Windowsコード署名](https://github.com/BLIMP-B/csv-nyaan-viewer/blob/main/docs/code-signing.md) を参照してください。

外部アカウントの実接続にはOAuthアプリ登録が必要で、実アカウントでの接続は未検証です。3Dは投影表示、地図は国単位です。Excel固有のグラフオブジェクト・ピボット等の完全互換はありません。Modern CSV無料版との完全な機能照合も未完了です。
