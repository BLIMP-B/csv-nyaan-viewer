Windows 10 / 11（x64）向け CSV nyaan Viewer 1.2.1です。

Assetsの `CSV-nyaan-Viewer-1.2.1-Windows-x64.zip` をすべて展開して `CSV nyaan Viewer.exe` を起動してください。Node.jsは不要です。

- 左サイド・グラフプレビュー・ファイル結合の、データとの境界に接したペイン内側へタブ状の閉じるボタンを追加しました。閉じた際の展開ボタンと同じ形状・テーマ色を使います。
- 既存の×ボタンを維持し、境界ボタンでも閉じられます。開き直してもペインのサイズ・内容・モードを保持します。
- ペインを上下左右へ移動すると境界ボタンも追随します。同じ側にプレビューと結合を配置しても、別々に閉じられます。境界ドラッグ・6箇所のドット型つまみも利用できます。
- ライト／ダークの視認性、ペイン内部への配置、つまみと重ならないこと、開閉・位置変更・同じ側への配置をElectronの画面操作で確認します。コア77件・UI24件の全101件をWindowsで実行し、アイコンとAuthenticode署名を検証して配布します。

v1.2.0の読み取り専用CSV・Excel・Markdown・TXT閲覧、テーブル管理、名前による範囲合流、変量・多変量分析、2D／3D操作、各種出力、テーマ、共有・接続機能を含みます。XLSXの分析グラフは画像として収録します。操作と上限はREADMEを参照してください。

検証用の自己署名版です。公開証明書 `test-signing.cer` と検証結果 `SIGNATURE.json` を配布します。以前の証明書を登録している場合は新しい拇印を確認して更新してください。手順は [Windowsコード署名](https://github.com/BLIMP-B/csv-nyaan-viewer/blob/main/docs/code-signing.md) を参照してください。

外部アカウントの実接続にはOAuth登録が必要で、実接続は未検証です。Excel固有のチャート・ピボットの完全互換、およびModern CSV無料版の完全な機能照合は未完了です。
