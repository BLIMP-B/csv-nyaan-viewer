Windows 10 / 11（x64）向け CSV nyaan Viewer 1.5.2です。

Assetsの `CSV-nyaan-Viewer-1.5.2-Windows-x64.zip` をすべて展開して `CSV nyaan Viewer.exe` を起動してください。Node.jsは不要です。

- 上部のアカウント欄の幅制限とバッジのはみ出しを修正し、登録数が1〜5件のどの場合もスクロールバーを表示せず収めます。最小ウィンドウ幅でもURL入力欄とテーマ切り替えを維持します。
- 各サービスへログインした本人のプロフィール画像を取得して丸く表示します。画像なし・取得失敗・権限不足では各サービスのアイコンを表示します。
- S接続では本人のアカウントボタンに表示された画像を取り込み、他のユーザーの画像を採用しません。保存済みの画像を再起動後も表示し、内部ブラウザの「画像を更新」で再取得できます。旧版で登録したS接続はサービス画面を開いた際に取得を試みます。
- 既存API接続はGoogle・Microsoft・GitHubの本人情報、権限のあるSlackユーザートークンから取得を試みます。Slack／DiscordのBot・Webhookはユーザー画像の対象外です。画像取得失敗は共有接続に影響せず、解除した接続の画像だけを消去します。

コア117件・Electron UI35件の全152件をWindowsで実行し、アイコンとAuthenticode署名を検証して配布します。登録数別のスクロール範囲、ライト・ダーク、本人画像・取得失敗・他人の画像の除外・更新・再起動復元・ログアウト時の削除を確認します。画像取得のAPI／ブラウザ検証には架空のサービスと画像を使用し、実アカウントでの取得・ログイン・送信は未検証です。サービス画面の変更や権限により取得できない場合はサービスアイコンを表示します。

検証用の自己署名版です。公開証明書 `test-signing.cer` と検証結果 `SIGNATURE.json` を配布します。以前の証明書を登録している場合は新しい拇印を確認して更新してください。手順は [Windowsコード署名](https://github.com/BLIMP-B/csv-nyaan-viewer/blob/main/docs/code-signing.md) を参照してください。

既存の閲覧・分析・グラフ・出力・ペイン移動・共有・接続・S共有・Sアカウント接続機能を含みます。
