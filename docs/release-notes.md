Windows 10 / 11（x64）向け CSV nyaan Viewer 1.5.6です。

Assetsの `CSV-nyaan-Viewer-1.5.6-Windows-x64.zip` をすべて展開して `CSV nyaan Viewer.exe` を起動してください。Node.jsは不要です。

- ドット型つまみをグラフプレビュー内の描画領域にのみ配置しました。上下左右・左上・右下の6か所でグラフの幅・高さを変更し、ペインとデータセル領域の寸法は変えません。各ペインに配置していたつまみは削除し、ペインのサイズ変更は境界のドラッグとキー操作で行います。グラフの最小寸法、比率保持、ダブルクリック／Homeの復元、Escによる取消にも対応します。
- ウィンドウサイズの変更でペインの横や下に空間が残る問題を修正しました。上下のペインとデータ領域は同じ幅、左右のペインは画面全体の高さを共有し、境界の操作でも隙間や重なりが生じないようにします。
- 幅・高さはデータ領域との比率で保持し、最小寸法に達すると止まります。広げると希望比率へ戻り、上下両方を展開する際はウィンドウの最小高さも連動してデータセルの領域を確保します。旧版のサイズ設定を移行し、開閉・再起動後も復元します。
- 初回起動にクリックしながら学ぶ全13段階のチュートリアルを追加しました。練習用CSVを使って、範囲選択、グラフ、テーブル、分析、結合、ペイン操作、検索、Markdown・TXT、出力、共有・接続、配色を確認できます。実際の操作部の強調表示、練習ボタン、進捗確認に対応します。
- チュートリアルはスキップ・途中終了でき、ヘルプから再実行できます。元のファイルや作業中のテーブル・結合ブロックを保持し、練習データだけを片付けて元のペイン配置へ戻ります。途中でアプリを閉じた場合も次回起動時に配置を復元します。

コア124件・Electron UI41件の全165件をWindowsで実行し、アイコンとAuthenticode署名を検証して配布します。既存のプロフィール画像取得と共有には模擬サービスを使用し、実アカウントのログイン・画像取得・送信は未検証です。

検証用の自己署名版です。公開証明書 `test-signing.cer` と検証結果 `SIGNATURE.json` を配布します。以前の証明書を登録している場合は新しい拇印を確認して更新してください。手順は [Windowsコード署名](https://github.com/BLIMP-B/csv-nyaan-viewer/blob/main/docs/code-signing.md) を参照してください。
